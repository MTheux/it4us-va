# Revisão SOC de infraestrutura

Use para consolidar uma tarefa ou campanha.

1. Verifique autorização, janela, escopo expandido, parâmetros, execução e recibo.
2. Faça uma tabela por candidato: ativo, evidência, hipótese, confiança, validação pendente, impacto plausível e responsável.
3. Classifique como `confirmado`, `provável`, `inconclusivo` ou `descartado` somente com base na evidência disponível.
4. Para achado confirmado, descreva causa, impacto, correção e teste de reteste. Para candidatos, descreva o que falta validar.
5. Preserve dados sensíveis fora do relatório; use identificadores mínimos e não copie credenciais, tokens ou PII.

Não confunda disponibilidade do scanner, resposta HTTP ou banner com comprovação de vulnerabilidade.
